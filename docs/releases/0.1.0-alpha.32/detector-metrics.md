# Detector metrics — 0.1.0-alpha.32

**No game compatibility is claimed in this release.** Every number below was measured on
original synthetic media generated by the repository's own fixtures. Synthetic results
show that the detectors behave as specified; they do not show how well they work on any
real game.

## Publication rule

A compatibility claim for a game (including GTA VI) may appear in release notes only with
all three of:

1. a published profile id and version;
2. a description of the evaluation footage: legally obtained after release, with the
   recorder's consent, its resolution, HUD scale, locale and compression, and the number
   of footage hours (footage itself is never committed);
3. the metrics produced by the local evaluation report (`owm eval run`, [M19](../../evaluation/README.md)): precision,
   recall, F1, false positives per hour, median timestamp error and processing speed.

No profile meets this rule for 0.1.0-alpha.32. The `open-world-vi` and `gta-v` profile
folders are unvalidated placeholders without regions, templates or metrics.

font, footage or game asset is committed. The only committed images are the original

records required.**

## Measured synthetic results

### Local evaluation holdout (M19)

Dataset `synthetic-temporal-holdout-v1`, profile `generic-open-world` 1.0.0, boundary
tolerance 0 ms ([report](../../evaluation/sample/report.md)).

| Precision | Recall | F1 | False positives/hour | Median timestamp error | Realtime factor |
|---:|---:|---:|---:|---:|---:|
| 1 | 1 | 1 | 0 | 0 ms | 6.16× |

Three events in 19 s of footage, two resolutions/compression levels. Status:
**synthetic-only**.

### Wanted indicator (M16, `generic-wanted` 1.0.0, detector 1.0.0)

- 138 static star/disc cases (maximum 1/3/5/10, every level, three brightness levels):
  correct level with score ≥ 0.8.
- Real H.264 encodes at 720p CRF 18, 1080p CRF 32 at 70% brightness and 4K CRF 38:
  exactly the expected 0→2→5→0 changes after import, proxy and decode.
- Negative cases (missing HUD, wrong shapes, compressed moving `testsrc2`): no state and
  no transitions.
- Speed: one hour of 2 fps ROI samples in a median 5.6 s (~643× real time) on an Apple M4,
  estimator only. Not a Windows CPU qualification.

Details: [wanted detector](../../detectors/wanted.md).

### Banners and subtitles (M17, `generic-text` 1.0.0)

- 36 banner cases (six categories × base, small, dim, outline, duplex, multiline): correct
  category, confidence ≥ 0.75, with the real local Tesseract engine.
- Requires an optional Tesseract install; without it the detectors report "unavailable",
  never a guess.

Details: [text detectors](../../detectors/text.md).

### Audio features (M18, `generic-audio` 1.0.0)

- Onset/impact start within ±20 ms on synthetic PCM and ±30 ms after the AAC proxy.
- Silence and speech-activity boundaries within ±150 ms.
- Ten synthetic minutes analysed in a median 0.156 s (~3,850× real time).
- Always supporting evidence; never a highlight on its own.

Details: [audio analysis](../../detectors/audio.md).

### Story windows (M20, `owm-story` 1.0.0)

All ten synthetic coverage cases pass ([report](../../stories/sample/report.md)). Median
manual boundary adjustment on real stories is **unmeasured**.

## Not measured

- Any detector on real gameplay from any game.
- Real speech-recognition accuracy of the optional whisper.cpp models.
- End-to-end analysis throughput on the minimum Windows hardware.
