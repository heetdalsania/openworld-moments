# Milestone Briefs

Each file in this directory defines one implementation milestone sized for a focused contributor or agent session.

Before executing a brief, read:

1. [Repository README](../../README.md)
2. [Product and engineering specification](../../OPENWORLD_MOMENTS_BUILD_SPEC.md)
3. [Milestone index and dependency graph](../../MILESTONES.md)
4. The selected milestone file

Milestone briefs are normative for scope and acceptance criteria. The broader specification is normative for product behavior and safety boundaries. If they conflict, stop and update the planning documents before implementation.

Every milestone concludes with a handoff. Do not mark a milestone complete if tests are skipped, acceptance criteria are partially met, or required documentation is missing.
